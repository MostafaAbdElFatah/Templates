### Production HTML and CSS

The root `index.html` continues to load the original HTML and unminified CSS for
development. To create a production-ready site with minified HTML and bundled,
minified CSS, run:

```sh
npm ci
npm run build
```

The complete deployable site is written to `dist/`. The build minifies the copied
HTML, copies the scripts and image assets, and bundles the CSS imports into a
minified stylesheet.
